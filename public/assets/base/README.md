# Pebble printable base + humanoid upper body

Wheeled differential base + **vertical torso** + **L/R shoulder pods** + **head** (screen bezel + camera).
Units: **millimeters**. Match `src/robot/dims.ts`.

## Design (first principles)
- SO-101 reach ~500 mm → shoulders at **~527 mm** AGL so idle hang reaches near floor and raised reach ≈ US counter (~900 mm).
- Overall height with head ≈ **717 mm**.
- Wider octagon base (**340 mm** flat-to-flat) + taller bay (**77 mm**) for dual-arm tip resistance / ballast.
- Default product: **2× SO-101** hanging at flanks.

## Honesty / tip risk
Draft — **not for sale**. Dual arms + taller COM raise tip risk on rugs/ramps — use **wide base + ballast** in the bay. Not a babysitter.

## Filament (PLA ~20% infill)
Rough: base + torso + head ≈ **550–750 g** + 2× arm sets ~600–800 g. Order 2 kg with margin.
