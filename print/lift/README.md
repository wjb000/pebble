# Lift prints — orientation + mates (poka-yoke)

**v3 sim lift is nested telescoping tubes** (BOM_V3) — not an exposed Prusa/MGN carriage.

Upstream Prusa GPL-2.0 Z parts remain as a **legacy archive**. **Keep using** SO-ARM `4040_base_mount.stl` (Apache-2.0) on the printed shoulder bar. See `NOTICE.md`.

**Bought — do not print:** nested column kit, internal T8. Twin shows tubes as metal envelopes.

## Orientation

| STL | Bed | Mate |
|-----|-----|------|
| `4040_base_mount.stl` | Flat; **print 2× — mirror one** | Shoulder bar L = +X **blue**; R = −X **orange** |
| `z-axis-bottom.stl` | Motor flange accessible | Legacy — unused in v3 twin |
| `z-axis-top.stl` | Bore vertical | Legacy — unused in v3 twin |
| `carriage_x-end-motor.stl` | Nut bore free | Legacy — unused in v3 twin |

Mark `L`/`R` with marker or paint. Wrong side = arm bus chaos.
